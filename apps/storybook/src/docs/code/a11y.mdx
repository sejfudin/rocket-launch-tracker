# Accessibility

It's important to provide at least base level of accessibility in every project. This project is set up to provide that.

## Axe accessibility testing

In development mode, we use [Axe](https://github.com/dequelabs/axe-core) to report accessibility issues. You can see the report in the browser console. Make sure to regularly check for issues - developing with accessibility in mind doesn't take much more time.

## Storybook

Storybook is configured with a11y plugin. Check the "Accessibility" tab to test your components.

## Additional learning

We highly encourage you read at least this resource: [HTML: A good basis for accessibility](https://developer.mozilla.org/en-US/docs/Learn/Accessibility/HTML).
