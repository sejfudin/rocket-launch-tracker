# Povio FE template

This is a template for the FE app, which includes tooling and configuration to launch SPA or SSR projects faster.

## Features

- Code formatter, linter
- A framework for fetching data, validating it, and handling errors
- Folder structure that abstracts away the framework and underlying libraries
- Sample code to get you started
- Tools for working with assets
- Font optimization
- Opt-in image optimization
- Can be deployed as static files
- Server-side rendering with Dockerfile for deployment
- Design system

For more information, consult the setup documentation for [macOS](../../docs/01_macOS.md) or [Windows](../../docs/01_Windows.md).

## Getting started

Create a new project using this template, then follow the setup guide for [macOS](../../docs/01_macOS.md) or [Windows](../../docs/01_Windows.md) to set up your project.

## Contributing

If you have any suggestions or improvements, please open an issue or a pull request. Your feedback is very welcome!

## Bundle visualizer

To inspect build bundle, use [rollup-plugin-visualizer](https://www.npmjs.com/package/rollup-plugin-visualizer).

## Feedback

The template is still in beta. We would love to hear your feedback on whether the template is simple enough to work with. We would love to hear if you have any troubles with it, or any suggestions for improvements. Reach out to maintainers on Slack for suggestions.

## Adding new features

The goal of this template is to contain all the patterns that we use at Povio on the frontend, so that we don't have to keep reinventing the wheel. If you've implemented something on your project that you feel like would be a good thing to put in the template, please contact maintainers on Slack. Your contributions are very welcome.
